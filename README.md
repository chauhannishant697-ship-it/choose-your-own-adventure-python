# Choose Your Own Adventure

This is a simple text-based adventure game made using Python.

In this game, every choice you make changes what happens next. Pick a path carefully because one wrong decision can end your adventure.

## Features

- Two different adventure paths
- Multiple endings
- Win and lose conditions
- User input based gameplay
- Simple and beginner-friendly code

## Technologies Used

- Python

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder.
4. Run:

```bash
python main.py
```

## Game Story

Choose where you want to start your adventure.

- Jungle 🌳
- Road 🛣️

Every decision leads to a different ending.
